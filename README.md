# ATECO 2025 Codes API with Profitability Coefficients

Italian ATECO 2025 business classification codes with the *regime forfettario* profitability coefficients, deployed as a static site on GitHub Pages.

## Live Demo

**URL:** `https://FeliceC.github.io/ateco_codes`

The web interface allows searching and filtering ATECO codes directly in the browser.

## Static API

| Endpoint | Content |
|----------|---------|
| `GET /ateco_codes_with_profitability.json` | Full dataset with metadata |
| `GET /api/code/{code}.json` | Single code, e.g. `/api/code/01.1.json` |
| `GET /api/stats.json` | Dataset statistics |

Search and filtering run client-side: load the full dataset and use the functions in `api.js`.

## Data

### `ateco_codes_with_profitability.json`
- **Total ATECO codes:** 3257 (all levels, sections included)
- **Codes with a single profitability coefficient:** 2791
- **Codes with ambiguous coefficient:** 466 (see below)

### `ateco_codes_with_profitability.sql`
`CREATE TABLE` + `INSERT` statements for PostgreSQL.

Both files are generated by `npm run generate` from the ISTAT sources in `data/`: do not edit them by hand.

## Data Format

```json
{
  "code": "01.1",
  "title_it": "Coltivazione di colture agricole non permanenti",
  "title_en": "Growing of non-perennial crops",
  "hierarchy": 3,
  "parent_code": "01",
  "profitability_coefficient": 0.67,
  "profitability_candidates": [0.67],
  "profitability_description": "Altre attività economiche",
  "profitability_category": "altre_attivita",
  "has_profitability_data": true
}
```

## Profitability Coefficients

Coefficients come from Allegato 4 of L. 190/2014 (as replaced by L. 145/2018), which is still in force for ATECO 2025 until a new table is approved (d.lgs. 81/2025). The law defines them on ATECO 2007/2022 codes:

| Category | ATECO 2007/2022 | Coefficient |
|----------|-----------------|-------------|
| Construction & Real Estate | 41-43, 68 | 86% |
| Professional/Financial Services | 64-66, 69-75, 85-88 | 78% |
| Other Economic Activities | everything else | 67% |
| Trade Intermediaries | 46.1 | 62% |
| Street Trade - Other Products | 47.82-47.89 | 54% |
| Food & Beverage Industry | 10-11 | 40% |
| Wholesale/Retail Trade | 45, 46.2-46.9, 47.1-47.7, 47.9 | 40% |
| Street Trade - Food | 47.81 | 40% |
| Accommodation & Food Services | 55-56 | 40% |

Each ATECO 2025 code is mapped to ATECO 2022 through the ISTAT correspondence table. When it corresponds to 2022 codes with different coefficients (e.g. `47.12.10` covers both shop and street retail), `profitability_coefficient` is `null` and `profitability_candidates` lists every possible value: the right one depends on the activity actually performed.

## Data Sources

`data/` holds the columns needed from these ISTAT files:

- `istat-structure-2025.tsv` — [Struttura ATECO 2025](https://www.istat.it/wp-content/uploads/2025/02/StrutturaATECO-2025-IT-EN-DE.xlsx)
- `istat-correspondence-2025-2022.tsv` — leaf rows of the [Tavola di raccordo ATECO 2025-2022, aggiornamento 2026](https://www.istat.it/wp-content/uploads/2026/07/Aggiornamento-2026-Tavola-raccordo-bidirezionale-ATECO-2025-ATECO-2022-italiano.xlsx)

## Local Development

```bash
git clone https://github.com/FeliceC/ateco_codes.git
cd ateco_codes
npm ci

# Run tests
npm test

# Regenerate JSON and SQL from data/
npm run generate

# Build static site into ./dist
npm run build

# Serve locally
npx serve dist
```

## Deployment

Push to `main` triggers GitHub Actions which:
1. Installs dependencies
2. Runs tests
3. Builds the static site
4. Deploys to GitHub Pages
